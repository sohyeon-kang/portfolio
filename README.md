# 강소현 포트폴리오

웹·앱 개발 프로젝트와 담당 역할, 문제 해결 과정을 소개하는 정적 웹사이트입니다.

- 사이트: https://sohyeon-kang.github.io/portfolio/
- 기억서랍: 문서 분석·추억 카드 저장을 위한 백엔드와 서비스 통합
- DUA: 여행 조건 선택·코스 추천·지하철 이동 안내 화면

## 실행

`index.html`을 브라우저에서 열거나, 이 폴더에서 `python -m http.server 8765`를 실행합니다.
별도 패키지 설치와 빌드 과정은 없습니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다.
수정 내용을 `main`에 커밋하고 푸시하면 사이트가 갱신됩니다.

이미지·글꼴·스크립트·시연 영상은 `assets/`에 포함됩니다.
기억서랍 시연 영상 버튼은 `assets/memory-demo.mp4`를 새 탭에서 엽니다.
작업 기록, 초안 PDF, 로컬 확인용 캡처는 저장소와 배포에서 제외합니다.

## 사용 자산

외부 글꼴과 GSAP의 출처·라이선스 안내는 [THIRD-PARTY-NOTICES](assets/THIRD-PARTY-NOTICES.txt)에 있습니다.
프로젝트 소개에는 직접 참여한 작업의 화면과 시연 영상을 사용합니다.
